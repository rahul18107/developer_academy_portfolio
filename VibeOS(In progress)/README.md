# VibeOS

## Overview 🏝

VibeOS is an ongoing project that aims to provide an AI-powered development environment where developers can describe what they want to build and interact with AI to turn those ideas into working software. The goal is to simplify the development workflow by combining AI-assisted coding with an interactive interface, making it easier to move from an idea to implementation. The project is currently under active development.

### 🔦 Role: Developer

### 🚉 Platform: Web

### 🔧 Tech stack: React, TypeScript, Node.js, AI
